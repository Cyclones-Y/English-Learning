# 2026-08-25 学习记录

## 学习目标

继续复习 `who` 关系从句和动词后的 `that` 内容从句，训练“过去分词后置修饰 + 内容从句 + 被动语态”的三层结构，并巩固 `before`、`until` 的时间顺序。

## 句子一

> Before the deployment is approved, the reviewer who checked the release notes must confirm that all changes listed in the ticket have been tested.

- `Before` 从句：`the deployment is approved`
- 主句主语和完整谓语：`the reviewer who checked the release notes` / `must confirm`
- `who checked the release notes` 修饰 `reviewer`。
- `that all changes listed in the ticket have been tested` 是 `confirm` 的内容从句。
- 内容从句主语：`all changes listed in the ticket`，完整谓语：`have been tested`。
- `listed in the ticket` 修饰 `changes`，不是内容从句的完整谓语。
- 时间顺序：工单中的修改完成测试 -> 审核人员确认 -> 部署获得批准。
- 自然翻译：在部署获得批准之前，检查过发布说明的审核人员必须确认，工单中列出的所有修改都已经过测试。

关键纠正：`confirm` 表示“确认事实”，不等于“确保做到”；`listed in the ticket` 是修饰语，`have been tested` 才是内容从句的完整谓语。

## 句子二

> The manager cannot approve the request until the documents submitted by the applicant have been verified by the employee who received them.

- 主句主语和完整谓语：`The manager` / `cannot approve`
- `until` 从句主语和完整谓语：`the documents submitted by the applicant` / `have been verified`
- `submitted by the applicant` 修饰 `documents`。
- `by the employee who received them` 说明核实动作的执行者。
- `who received them` 修饰 `employee`；`them` 指 `the documents`。
- 时间顺序：申请人提交文件 -> 员工收到并核实 -> 经理批准申请。
- 自然翻译：在收到文件的员工核实申请人提交的文件之前，经理不能批准该申请。

## 句子三

> The feature that was requested by the support team cannot be released until the developer who built it confirms that the test cases written for it have all passed.

- 主句主语和完整谓语：`The feature that was requested by the support team` / `cannot be released`
- `that was requested by the support team` 修饰 `feature`。
- `until` 从句主语和完整谓语：`the developer who built it` / `confirms`
- `who built it` 修饰 `developer`，`it` 指 `the feature`。
- `that the test cases written for it have all passed` 是 `confirms` 的内容从句。
- 内容从句主语：`the test cases written for it`，完整谓语：`have all passed`。
- `written for it` 修饰 `test cases`，`it` 指 `the feature`。
- 时间顺序：支持团队提出功能 -> 开发人员构建功能并编写测试用例 -> 测试用例全部通过 -> 开发人员确认 -> 功能发布。
- 自然翻译：支持团队要求的功能，在构建它的开发人员确认针对该功能编写的测试用例已全部通过之前，不能发布。

关键纠正：`developer` 是单个“开发人员”，不是“开发团队”；`written for it` 是“针对该功能编写的”，不是泛指“写完测试用例”。

## 重点词汇

| 词汇或搭配 | 中文含义 | 当日用法 |
| --- | --- | --- |
| release notes | 发布说明 | `the reviewer who checked the release notes` |
| reviewer | 审核人员 | `the reviewer who checked...` |
| confirm that | 确认（事实） | `must confirm that...` |
| be tested | 经过测试 | `all changes have been tested` |
| feature | 功能 | `The feature cannot be released.` |
| support team | 支持团队 | `requested by the support team` |
| developer | 开发人员 | `the developer who built it` |
| test cases | 测试用例 | `the test cases written for it` |
| pass a test | 通过测试 | `the test cases have all passed` |
