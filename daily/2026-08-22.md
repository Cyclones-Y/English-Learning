# 2026-08-22 学习记录

## 学习目标

复习主句和从句，强化完整谓语，并在一个句子中同时处理条件、修饰和时间关系。

## 句子一

> Although the customer provided all the required information, the request was still rejected.

- `Although` 从句：`the customer provided all the required information`
- 从句主语和谓语：`the customer` / `provided`
- 主句：`the request was still rejected`
- 主句完整谓语：`was still rejected`
- 自然翻译：尽管客户提供了所有必需的信息，该申请仍然被拒绝了。

关键纠正：不能只把 `was` 当作完整谓语；`was still rejected` 要整体理解。

## 句子二

> The application cannot be processed because the document that you uploaded is no longer valid.

- 主句：`The application cannot be processed.`
- 主句完整谓语：`cannot be processed`
- 原因从句：`the document that you uploaded is no longer valid`
- `that you uploaded` 修饰 `the document`。
- 自然翻译：该申请无法处理，因为你上传的文件已经失效。

## 句子三

> If the document that you submitted has expired, you must upload a new one before the application can be processed.

- `If` 从句：`the document that you submitted has expired`
- `that you submitted` 修饰 `the document`。
- 主句：`you must upload a new one before...`
- 主句完整谓语：`must upload`
- `one` 指代 `document`。
- `before` 从句：`the application can be processed`
- 时间顺序：原文档已经过期 -> 上传新文档 -> 申请才能得到处理。
- 自然翻译：如果你提交的文档已经过期，那么必须先上传一份新文档，申请才能得到处理。

关键纠正：`before` 修饰“申请得到处理”的时间界限，不表示“在文档过期前上传”。

## 重点词汇

| 词汇或搭配 | 中文含义 | 当日用法 |
| --- | --- | --- |
| be rejected | 被拒绝 | `was still rejected` |
| be processed | 被处理 | `cannot be processed` |
| is no longer valid | 已经失效／不再有效 | 描述上传文件状态 |
| has expired | 已经过期 | 描述文档已经过期 |
