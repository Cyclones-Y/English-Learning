# 2026-10-19 学习记录

## 学习目标

对比 `is being updated`、`has been updated` 和 `can be updated`，区分正在进行、已经完成和可以发生，并复习 `without + doing`。

## 句子一

> The primary system is being updated, so the backup server must remain online.

- 前一分句的主语和完整谓语：`The primary system` / `is being updated`。
- 后一分句的主语和完整谓语：`the backup server` / `must remain`；`online` 是持续状态。
- `so` 表示“原因 -> 结果”：因为主系统正在被更新，所以备用服务器必须保持在线。
- `is being updated` 是进行时被动语态，表示更新动作正在进行。
- 自然翻译：主系统正在被更新，所以备用服务器必须保持在线。

关键纠正：学习者准确理解了句意和结果关系；中文“主系统正在更新”自然，但“正在被更新”更明确地保留了原文的被动语态。

## 句子二

> The primary system has been updated, so the backup server can be stopped.

- 前一分句的主语和完整谓语：`The primary system` / `has been updated`。
- 后一分句的主语和完整谓语：`the backup server` / `can be stopped`。
- `has been updated` 表示更新已经完成；`can be stopped` 只表示现在具备停止条件，不表示已经停止。
- 自然翻译：主系统已经被更新，所以备用服务器可以被停止。

关键纠正：学习者准确理解了完成含义；“暂停”通常对应 `pause`，而 `stop` 在技术场景中更适合译为“停止／停用”。

## 句子三

> The primary system can be updated without stopping the monitoring service.

- 主语和完整谓语：`The primary system` / `can be updated`。
- `without stopping the monitoring service` 修饰更新主系统的动作。
- `without + doing` 表示“不做某事／无需做某事”。
- `can be updated` 表示主系统能够或可以被更新，不表示更新正在进行或已经完成。
- 自然翻译：主系统可以被更新，无需停止监控服务。

关键表现：学习者准确保留了情态被动含义，也自然地把 `without stopping...` 译成“无需停止……”。

## 重点词汇

| 词汇或搭配 | 中文含义 | 当日用法 |
| --- | --- | --- |
| is being updated | 正在被更新 | 动作正在进行 |
| has been updated | 已经被更新 | 动作已经完成 |
| can be updated | 可以被更新 | 表示能力或可能性 |
| can be stopped | 可以被停止／停用 | 不表示已经停止 |
| without stopping | 无需停止；在不停止的情况下 | `without stopping the monitoring service` |

## 当日总结

- 已掌握：能够根据完整谓语准确区分“正在被更新”“已经被更新”和“可以被更新”。
- 已掌握：能够正确理解 `without stopping...`，没有再次逐词拼接 `without + doing`。
- 仍需复习：技术场景中区分 `stop`（停止／停用）与 `pause`（暂停），并继续主动标出完整谓语。
- 下一课建议：在不提前提示语态类型的长句中混合使用三种被动形式，并复习 `stop`、`pause`、`restart` 的动作差异。
