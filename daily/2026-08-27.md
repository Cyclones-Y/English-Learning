# 2026-08-27 学习记录

## 学习目标

复习“过去分词后置修饰 + 内容从句 + 被动谓语”，巩固 `before`、`until` 和 `although` 的逻辑关系，并重点区分 `has/have been done` 与 `can be done`。

## 句子一

> Before the service can be restarted, the engineer who reviewed the logs must confirm that the configuration changed during maintenance has been restored correctly.

- `Before` 从句：`the service can be restarted`。
- 主句主语和完整谓语：`the engineer who reviewed the logs` / `must confirm`。
- `who reviewed the logs` 修饰 `engineer`。
- `that the configuration changed during maintenance has been restored correctly` 是 `confirm` 的内容从句。
- 内容从句主语：`the configuration changed during maintenance`；完整谓语：`has been restored correctly`。
- `changed during maintenance` 修饰 `configuration`，可展开为 `that was changed during maintenance`。
- 时间顺序：配置恢复 -> 工程师确认 -> 服务重启。
- 自然翻译：在服务可以重启之前，检查过日志的工程师必须确认，维护期间更改的配置已经被正确恢复。

关键纠正：学习者起初把 `has been restored` 译为“能够被恢复”；经对比后确认它表示恢复已经完成，而 `can be restored` 才表示具备恢复的可能或能力。

## 句子二

> The administrator must verify that the permissions assigned to the temporary account have been removed before the contractor who used it leaves the project.

- 主句主语和完整谓语：`The administrator` / `must verify`。
- `that the permissions assigned to the temporary account have been removed` 是 `verify` 的内容从句。
- 内容从句主语：`the permissions assigned to the temporary account`；完整谓语：`have been removed`。
- `assigned to the temporary account` 修饰 `permissions`。
- `who used it` 修饰 `contractor`；`it` 指 `the temporary account`。
- 时间顺序：权限移除 -> 管理员核实 -> 外包人员离开项目。
- 自然翻译：管理员必须在使用该临时账户的外包人员离开项目之前，核实分配给该账户的权限已经被移除。

关键纠正：没有把“分配给账户的权限”改写成“分配给外包人员的账户权限”；原文也没有表达“完全移除”。

## 句子三

> Although the developer who implemented the fix confirmed that the reported issue had been resolved, the updated service cannot be deployed until the security team approves it.

- `Although` 从句主语和完整谓语：`the developer who implemented the fix` / `confirmed`。
- `who implemented the fix` 修饰 `developer`。
- `that the reported issue had been resolved` 是 `confirmed` 的内容从句；其中 `had been resolved` 表示在确认之前问题已经被解决。
- 主句主语和完整谓语：`the updated service` / `cannot be deployed`。
- `reported` 修饰 `issue`；`updated` 修饰 `service`。
- `it` 指 `the updated service`。
- 逻辑顺序：问题解决 -> 开发人员确认 -> 安全团队批准 -> 服务才能部署。
- 自然翻译：尽管实施修复方案的开发人员确认已报告的问题已经解决，但在安全团队批准更新后的服务之前，该服务仍不能部署。

关键纠正：学习者把 `had been resolved` 当成了 `Although` 从句的完整谓语；该从句的完整谓语是 `confirmed`，`had been resolved` 属于 `confirmed` 后的内容从句。`approve` 在此表示“批准”，不是“通过测试”。

## 重点词汇

| 词汇或搭配 | 中文含义 | 当日用法 |
| --- | --- | --- |
| restart the service | 重启服务 | `the service can be restarted` |
| configuration | 配置；配置项 | `the configuration changed during maintenance` |
| during maintenance | 在维护期间 | `changed during maintenance` |
| temporary account | 临时账户 | `assigned to the temporary account` |
| remove permissions | 移除权限 | `the permissions have been removed` |
| implement a fix | 实施修复方案 | `the developer who implemented the fix` |
| had been resolved | 已经被解决 | 表示问题在另一个过去动作之前已解决 |
| approve a service | 批准服务 | `the security team approves it` |

## 当日总结

- 已掌握：能独立识别过去分词后置修饰的对象，并找到内容从句中的主语整体和完整被动谓语。
- 仍需复习：`has/have been done` 与 `can be done`；多层句中要区分外层谓语和内容从句谓语；翻译时避免添加“完全”等原文没有的程度。
- 下一课建议：用一条包含 `although + confirm that + 过去完成时` 的句子进行间隔复习，再加入一个新的连接结构。
