# 2026-08-29 学习记录

## 学习目标

复习“过去分词后置修饰 + `confirm that` 内容从句 + 被动谓语”的三层结构，引入新连接词 `once`，并巩固 `unless`、`after` 的条件和时间关系。

## 句子一

> Once the engineer who reviewed the logs confirms that the records deleted by mistake have been recovered, the service can be restarted.

- `Once` 从句主语和完整谓语：`the engineer who reviewed the logs` / `confirms`
- 主句主语和完整谓语：`the service` / `can be restarted`
- `who reviewed the logs` 修饰 `the engineer`
- `that the records deleted by mistake have been recovered` 是 `confirms` 的内容从句
- 内容从句主语：`the records deleted by mistake`，完整谓语：`have been recovered`
- `deleted by mistake` 修饰 `the records`
- 逻辑顺序：记录被误删 -> 记录恢复 -> 工程师确认 -> 服务可以重启
- 自然翻译：一旦检查过日志的工程师确认被误删的记录已经被恢复，服务就可以重启。

关键纠正：`once` 表示“一旦……就……”，强调确认动作发生后服务才具备重启条件。

## 句子二

> The deployment cannot proceed unless the administrator confirms that the permissions assigned to the new account have been verified.

- 主句主语和完整谓语：`The deployment` / `cannot proceed`
- `unless` 从句主语和完整谓语：`the administrator` / `confirms`
- `that the permissions assigned to the new account have been verified` 是 `confirms` 的内容从句
- 内容从句主语：`the permissions assigned to the new account`，完整谓语：`have been verified`
- `assigned to the new account` 修饰 `the permissions`
- 条件关系：核实权限是部署的必要条件，不保证核实后一定部署
- 自然翻译：除非管理员确认分配给新账户的权限已经被核实，否则部署不能继续进行。

关键纠正：`assigned to the new account` 是修饰 `permissions` 的过去分词短语，不是单独的“权限被分配给了新账户”。

## 句子三

> After the contractor who replaced the broken server confirms that the data stored on the old disk has been transferred, the backup files can be deleted.

- `After` 从句主语和完整谓语：`the contractor who replaced the broken server` / `confirms`
- 主句主语和完整谓语：`the backup files` / `can be deleted`
- `who replaced the broken server` 修饰 `the contractor`
- `that the data stored on the old disk has been transferred` 是 `confirms` 的内容从句
- 内容从句主语：`the data stored on the old disk`，完整谓语：`has been transferred`
- `stored on the old disk` 修饰 `the data`
- 时间顺序：数据从旧磁盘转移 -> 外包人员确认转移已完成 -> 备份文件可以删除
- 自然翻译：更换损坏服务器的外包人员确认存储在旧磁盘上的数据已经转移之后，备份文件就可以删除了。

关键纠正：`broken server` 是“损坏的服务器”；`has been transferred` 是被动语态“已经被转移”，不是主动的“完成转移”。

## 重点词汇

| 词汇或搭配 | 中文含义 | 当日用法 |
| --- | --- | --- |
| once | 一旦……就…… | `Once the engineer confirms...` |
| deleted by mistake | 被误删的 | `the records deleted by mistake` |
| be recovered | 被恢复 | `the records have been recovered` |
| proceed | 继续进行 | `The deployment cannot proceed.` |
| new account | 新账户 | `assigned to the new account` |
| contractor | 外包人员 | `the contractor who replaced...` |
| broken server | 损坏的服务器 | `replaced the broken server` |
| transfer data | 转移数据 | `the data has been transferred` |
| old disk | 旧磁盘 | `stored on the old disk` |

## 当日总结

- 已掌握：能独立识别主句、`once`/`unless`/`after` 从句及各部分完整谓语。
- 仍需复习：把过去分词修饰语保持为一个整体，不要把 `assigned to...` 拆成独立动作。
- 仍需复习：被动语态 `has been transferred` 与主动“完成转移”的区别。
- 下一课建议：继续用一条含 `once` 或 `after` 的多层句做间隔复习，再引入一个目的或结果结构。
