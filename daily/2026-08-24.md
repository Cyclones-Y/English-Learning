# 2026-08-24 学习记录

## 学习目标

复习 `who` 关系从句和动词后的 `that` 内容从句，继续区分过去分词修饰语与完整谓语，并训练多个 `before` 同时出现时的结构和时间顺序。

## 句子一

> After the engineer who reviewed the logs confirms that the missing records have been restored, the system can be restarted.

- `After` 从句主语和完整谓语：`the engineer who reviewed the logs` / `confirms`
- 主句主语和完整谓语：`the system` / `can be restarted`
- `who reviewed the logs` 修饰 `engineer`。
- `that the missing records have been restored` 是 `confirms` 的内容；其中主语和完整谓语是 `the missing records` / `have been restored`。
- 时间顺序：缺失记录恢复 -> 工程师确认 -> 系统可以重新启动。
- 自然翻译：检查过日志的工程师确认缺失记录已经恢复后，系统就可以重新启动了。

关键纠正：`missing records` 是“缺失的记录”，不是“确实的部分”；`can be restarted` 表示“可以重新启动”。

## 句子二

> The report that was generated from the logs cannot be shared until the analyst who prepared it removes the confidential details.

- 主句主语和完整谓语：`The report that was generated from the logs` / `cannot be shared`
- `that was generated from the logs` 修饰 `report`；从句完整谓语是 `was generated`。
- `until` 从句主语和完整谓语：`the analyst who prepared it` / `removes`
- `who prepared it` 修饰 `analyst`；`it` 指 `the report`。
- 时间顺序：分析员删除机密细节 -> 报告才可以分享。
- 自然翻译：由日志生成的报告，在准备这份报告的分析员删除机密细节之前，不能对外分享。

关键纠正：`the analyst who prepared it` 是“准备这份报告的分析员”，不是“准备好的分析员”。

## 句子三

> The administrator must confirm that the backup created before the update can be restored before the original files are deleted.

- 主句主语和完整谓语：`The administrator` / `must confirm`
- `that the backup created before the update can be restored` 是 `confirm` 的内容。
- 内容从句主语和完整谓语：`the backup created before the update` / `can be restored`
- `created before the update` 修饰 `backup`，可以展开为 `that was created before the update`。
- 句末的 `before the original files are deleted` 说明确认动作必须早于删除动作。
- 时间顺序：创建备份 -> 更新 -> 确认备份能够恢复 -> 删除原始文件。
- 自然翻译：管理员必须在删除原始文件之前，确认在更新前创建的备份能够恢复。

关键纠正：动词 `confirm` 后的 `that` 引出确认内容，不修饰前面的整句话；两个 `before` 分别位于不同结构层级。

## 重点词汇

| 词汇或搭配 | 中文含义 | 当日用法 |
| --- | --- | --- |
| review the logs | 检查日志 | `the engineer who reviewed the logs` |
| missing records | 缺失的记录 | `the missing records have been restored` |
| confidential details | 机密细节 | `removes the confidential details` |
| restore a backup | 恢复备份 | `the backup can be restored` |
| original files | 原始文件 | `before the original files are deleted` |

- 仍需加强主语边界，避免把过去分词修饰语拆成主句动作。
