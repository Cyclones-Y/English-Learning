# 重点词汇与固定搭配

| 表达 | 含义 | 例句或说明 | 状态 |
| --- | --- | --- | --- |
| access to | 对……的访问权限 | `need access to confidential files` | 复习中 |
| approve a request | 批准申请 | `The manager approves the request.` | 已理解 |
| be approved | 被批准 | 完整谓语要包含 `be` 的变化形式 | 复习中 |
| be rejected | 被拒绝 | `The request was still rejected.` | 复习中 |
| by Friday | 最迟在星期五 | 包含星期五当天，不等于必须早于星期五 | 已理解 |
| come to a complete stop | 完全停止 | 常见于设备安全提示 | 已理解 |
| confidential files | 机密文件 | `access to confidential files` | 已理解 |
| enter information manually | 手动录入信息 | `enter` 是录入，`manually` 是手动地 | 复习中 |
| feel dizzy | 感到头晕 | 运动安全提示 | 已理解 |
| gradually increase the speed | 逐渐提高速度 | 跑步机提示 | 已理解 |
| has expired | 已经过期 | `The document has expired.` | 已理解 |
| import information automatically | 自动导入信息 | 与手动录入形成对比 | 已理解 |
| investigate the issue | 调查问题 | 常用于系统维护通知 | 已理解 |
| is no longer valid | 已经失效／不再有效 | `no longer` 表示“不再” | 已理解 |
| need access to | 需要访问……的权限 | `need` 是从句中的动词 | 复习中 |
| provided by the applicant | 由申请人提供的 | 过去分词短语修饰前面的名词 | 复习中 |
| reduce the speed | 降低速度 | 运动安全提示 | 已理解 |
| remain unavailable | 一直处于不可用状态 | `remain + adjective` | 复习中 |
| required information | 必要信息／必填信息 | `required` 修饰 `information` | 已理解 |
| running pace | 跑步速度／跑步节奏 | `a comfortable running pace` | 已理解 |
| step off the treadmill | 从跑步机上下来 | `step off` 整体理解 | 已理解 |
| submit a request | 提交申请 | 不要与 `provide information` 混淆 | 已理解 |
| take a short break | 短暂休息一下 | `take a break` 是固定搭配 | 已理解 |
| until further notice | 直至另行通知 | 当前状态持续到收到后续通知 | 已理解 |
| unusually tired | 异常疲劳 | 不只是普通的“非常累” | 已理解 |
| verify information | 核实信息 | `verify that...` 表示核实某个内容 | 复习中 |
| warm up / warm-up | 热身／热身活动 | 前者常作动词，后者可作名词 | 已理解 |
| without further notice | 不再另行通知 | 不等于 `until further notice` | 已理解 |
